# Medical Appointment Data Cleaning Project

## 📌 Project Overview
This project focuses on cleaning and inspecting a medical appointments dataset to understand patient appointment records and identify data quality issues.

The dataset contains information about patients, appointment dates, medical conditions, SMS notifications, and whether patients attended their scheduled appointments.

## 🎯 Project Objectives
- Understand the structure of the medical appointments dataset.
- Check for missing and duplicate records.
- Inspect column names and data types.
- Understand patient demographics.
- Explore appointment attendance and no-show patterns.
- Prepare the dataset for further analysis.

## 📂 Dataset Information
- **Total Records:** 110,526
- **Total Columns:** 14
- **Female Patients:** 71,839
- **Male Patients:** 38,687
- **Age Range:** 0–115 years

## 🛠️ Tools & Technologies
- Python
- Pandas
- Jupyter Notebook

## 🧹 Data Cleaning & Quality Checks
The following data quality checks were performed on the provided cleaned dataset:

1. Loaded and inspected the CSV file.
2. Checked the dataset dimensions.
3. Checked for missing values.
4. Checked for duplicate rows.
5. Inspected column names and data types.
6. Reviewed patient age and appointment information.

## 📊 Key Findings
- The dataset contains 110,526 appointment records.
- No missing values were found.
- No duplicate rows were found.
- 88,207 appointments were marked as attended.
- 22,319 appointments were marked as no-show.
- Female patient records are higher than male patient records.
